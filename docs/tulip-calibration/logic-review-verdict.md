# Closing the TULIP scoring logic review

## Decision now

Reject the old capped severity/reach/duration product as the replacement rule for **aggregate current attributable harm**. The completed [mixed-case review](./mixed-case-calibration-decision.md) shows compatible burden-order reversals and premature saturation. A power curve applied afterward cannot recover distinctions already discarded by those inputs.

Continue with **source-native consequences, fixed external reference cases, and a versioned benchmark mapping**. Map the people and nature components separately onto 1–10. The fixed-average candidate retains 50/50 weights for every complete composite; a domain-only reading is a separate diagnostic, not a comparable TULIP rating. Missing evidence is not an exclusion or a zero. The user confirmed fixed 50/50 averaging on 28 September 2026. Its combined meaning is settled; keep the architecture experimental until its consequence conversions and numerical calibration are approved.

The architecture decision does not need another dataset. This closes the logic-review stage; further source research belongs to calibration and node assessment.

The [executable benchmark calculator](./benchmark-score-kernel.md) now implements the frozen-protocol sequence, separately maps components before averaging, and preserves precision through final rounding. Its mechanical checks do not approve the remaining calibration choices.

## Rules that must survive a new node

1. **The meaning stays fixed.** Measure current attributable consequences with declared geography, timebase and comparison case. Exposure, dependence and physical anomalies need a supported route to consequences.
2. **The ruler stays fixed.** Anchors, denominators, weights, ecosystem hierarchy and conversion rules live outside node assessments. Never normalize against the current catalogue's minimum, maximum, average or ranks.
3. **The calculation is reproducible.** Bind quantities to versioned source observations. Preserve continuous magnitude until the benchmark mapping; round only the final public value. Stocks, annual flows and lifetime losses need explicit compatible accounting rules.
4. **A new node uses an established evidence route.** Direct observation, a causal model or a reviewed transfer analogue must follow a specified conversion. An unfamiliar outcome or ecosystem requires extending and versioning the method, not an assessor inventing a private weight.
5. **Overlap does not create harm.** Count a shared consequence once. Splitting a node or ecosystem into labels must not create extra burden; scores of overlapping nodes are not additive.
6. **Comparable changes behave predictably.** Equivalent units preserve results. More harm with everything else fixed cannot lower a score. Adding an unrelated node cannot change an existing result. Any declared upper ceiling is distinguished from early input saturation.
7. **Evidence updates and method updates are different.** New evidence may change that node's result under the same method. Changing the ruler creates a new method version and requires a catalogue-wide comparison.

These rules make the method extensible. They cannot guarantee a defensible numerical rating for an arbitrary future phenomenon with no consequence evidence or transferable analogue. Future numerical coverage is an evidence-admission responsibility.
