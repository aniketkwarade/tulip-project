# Start TULIP internal calibration

Prepared 22 September 2026. Status: **internal method development**.

**Latest candidate, 28 September:** the [consequence rulebook and catalogue report](./consequence-calibration-candidate-2026-09-28.md) implements proposed nature and non-health human routes with fixed 50/50 averaging. All 381 research records are prepared; zero complete replacement ratings are admitted. The ecological thresholds and human-function bridge are explicit experimental TULIP choices, not completed scientific calibration. Public scores remain unchanged. Earlier status entries below are historical method-development records.

The launch goal is numerical TULIP ratings supported by evidence. The catalogue migration supplied the plumbing; it did not calibrate the scientific method. TULIP will define and test its own scoring logic first. Outside reviewers may later challenge the finished internal method and reproduce selected cases; they do not devise the scores.

**Current public contract:** TULIP now publishes one decimal score from 1.0 to 10.0. It does not publish A–E bands or verbal severity tags. Older internal artifacts retain their original letter fields only as an immutable audit trail and are not consumed by the app. See the [decimal-score readiness report](../../artifacts/tulip-calibration-2026-09-22/decimal-score-readiness-report.md) for the current catalogue and platform checks.
